# ПАО "НБД-Банк" — Сервис подписания документов УКЭП

Веб-сервис для подписания документов усиленной квалифицированной электронной подписью (УКЭП) через плагин КриптоПро.

## Возможности

### Для клиентов
- Вход по одноразовой ссылке на email (magic-link, TTL 10 часов).
- Загрузка, просмотр, скачивание документов.
- Подписание УКЭП через плагин КриптоПро (CAdES-BES).
- Несколько подписей на один документ.
- Скачивание подписи отдельно или архивом.
- Разделы (папки) для группировки документов.

### Для администраторов
- Вход по УКЭП-сертификату (без пароля).
- Управление клиентами и документами.
- **Визуализация подписей**: генерация PDF, где на каждой странице внизу красуется логотип Банка и текст «Документ подписан...», а на последней странице добавляются аккуратные синие штампы с данными сертификатов и доверенностей.
- Управление доверенностями (ЭМЧД).
- Журнал аудита с экспортом в CSV.
- **Модуль очистки мусора**: удаление старых логов, кэша Docker, файлов-сирот и старых бэкапов одной кнопкой.

### Безопасность
- Шифрование файлов документов (AES-256-GCM).
- Шифрование PII: email, телефон, ФИО (AES-256-GCM).
- Шифрование бэкапов БД (AES-256-CBC).
- Проверка подписи: BouncyCastle + проверка цепочки + CRL.
- Rate limiting (защита от брутфорса).
- Запрет удаления подписанных документов.

## Стек технологий
| Слой | Технология |
|---|---|
| Backend | Java 17, Spring Boot 3.2.5 |
| БД | PostgreSQL 15 (Astra Linux SE 1.8) + Flyway |
| ORM | Spring Data JPA, Hibernate 6 |
| Криптография | BouncyCastle, КриптоПро JCSP (ГОСТ) |
| Шифрование | AES-256-GCM, AES-256-CBC |
| Frontend | Thymeleaf, JS, CryptoPro CAdES Plugin |
| PDF | Apache PDFBox (визуализация подписей) |
| Инфраструктура | Docker Compose, Angie (ФСТЭК) |

## Развёртывание (Production)

1. Склонировать репозиторий на сервер:
   `git clone git@github.com:sigmabigdata/AfinaZ.git /opt/afinaz`
2. Подготовить секреты в `/opt/afinaz/secrets/`:
   `file.key`, `pii.key`, `backup.pass` (сгенерировать через `openssl rand -base64 32`).
3. Заполнить `.env.prod` (пароли БД, SMTP, домен) и `admins.env` (ФИО|СНИЛС).
4. Запустить:
   `docker compose -f docker-compose-prod.yml --env-file .env.prod up -d --build`
