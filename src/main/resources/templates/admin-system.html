Почему размер БД не уменьшается при удалении? Файлы документов хранятся на диске в storage/documents/, в БД — только метаданные. PostgreSQL не уменьшает размер файла БД при DELETE — освободившееся место переиспользуется (autovacuum). Реальный размер файлов смотри в карточке «Файлы (storage)» выше.
