Списки отзыва сертификатов (CRL)

Автоматическая загрузка: фоновый сервис каждые 6 часов обновляет CRL по CDP-URL из сертификатов подписантов. Файлы кладутся в /app/crls, дедуплицируются по издателю (issuer). Файлы auto-*.crl — автоматические, остальные — загружены вручную.

CRL обновляются автоматически каждые 6 часов (фоновый сервис). После каждого обновления старые файлы с тем же издателем заменяются. Если нужно обновить прямо сейчас — afina restart (первая проверка через 5 минут после старта).

Загрузить CRL вручную

Файл должен быть в формате X.509 CRL (DER или PEM). Скопируйте файл с сайта вашего УЦ.
