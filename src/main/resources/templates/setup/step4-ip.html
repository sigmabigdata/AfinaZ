Позже можно изменить в /admin/settings.
Через запятую. Одиночные IP (203.0.113.5) или CIDR-подсети (10.0.0.0/8).
Текущее значение по умолчанию: 127.0.0.1,::1,172.0.0.0/8 (localhost + приватные Docker-подсети).
🔒
Лучшая практика: администраторы заходят в /admin через VPN или ssh-туннель, поэтому whitelist обычно содержит только 127.0.0.1 и корпоративные подсети.
