Что делать со скачанным архивом

🔒 Бэкап защищён паролем (AES-256) внутри ZIP. Пароль задаётся при скачивании и нигде не сохраняется — без него архив не открыть. Сразу после скачивания перенесите файл в защищённое место и удалите из Downloads.
  1. Скачать ZIP через кнопку выше.
  2. Сохранить три копии в трёх разных местах:
    • Менеджер паролей (1Password, KeePass) — вложением
    • Бумага с содержимым ключей — в сейф
    • Зашифрованная флешка — в сейф (второе место)
  3. Удалить ZIP из Downloads.
  4. Сохранить пароль от ZIP отдельно от архива (в 1Password — в отдельной записи, не вложением).
  5. Отметить дату в своём журнале (или проверить счётчик выше).

Правила безопасности

✅ Разрешено Менеджер паролей (1Password, KeePass)
✅ Разрешено Бумага в сейфе
✅ Разрешено Зашифрованный архив на флешке в сейфе
❌ Запрещено Передача по email, мессенджерам, в чатах без шифрования
❌ Запрещено Хранение в git, в файлах .env, в публичных облаках
❌ Запрещено Одновременная передача архива и пароля в одном канале

Чего делать нельзя

Не заменять файлы ключей. Если перезаписать file.key или pii.key новым содержимым — все данные, зашифрованные старым ключом, будут безвозвратно потеряны. Никакой утилиты для безопасной ротации пока нет. Не редактируйте эти файлы вручную.
Не удалять ключи. Приложение не запустится без них. Файлы должны лежать по путям /opt/afinaz/secrets/file.key и /opt/afinaz/secrets/pii.key с правами 600 и владельцем 999:999.

При переезде на новый сервер

  1. Остановить приложение.
  2. Скопировать /opt/afinaz/secrets/ на новый сервер.
  3. Скопировать базу данных (pg_dump → pg_restore).
  4. Скопировать /opt/afinaz/storage/documents/.
  5. Проверить права: chown 999:999, chmod 600.
  6. Запустить приложение. Всё расшифруется теми же ключами.

Без ключей база и файлы будут нечитаемым мусором. Никогда не переезжайте без копии ключей.

🔒 Защита архива с ключами

Архив содержит file.key и pii.key — без них восстановить данные невозможно. Задайте пароль не короче 12 символов.

⚠️ Пароль не сохраняется в приложении. Если забудете — распаковать архив будет невозможно.
⚠️ Храните пароль отдельно от архива (менеджер паролей).

Альтернатива через CLI: afina key — покажет информацию о ключах, но не выгрузит их. Для выгрузки используйте эту форму.
